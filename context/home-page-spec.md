# Eclipcity Home Page Specification

## Призначення

Цей документ описує головну сторінку сайту Eclipcity: структуру, візуальний напрям, основні блоки, контент і базову поведінку.

Головна сторінка має одночасно виконувати три задачі:

1. Представити Eclipcity як нуарну cyberpunk-гру.
2. Дати швидкий доступ до реєстрації або авторизації.
3. Підготувати користувача до входу в мультиплеєрну частину гри.

## Дизайн-джерело

Для кольорів і типографіки використовувати:

`context/cyberpunk-color-palette-spec.md`

Ключова атмосфера: "Neon Wet Asphalt" - темний інтерфейс, неонові акценти, відчуття мокрого асфальту, нічного міста, тунелю й цифрової втечі.

## Шрифти

1. Загальний текст: `Space Mono`.
2. HUD, цифри, коди, технічні значення: `Share Tech Mono`.
3. Заголовки й назва гри: `Audiowide`.

Назва гри `Eclipcity` має використовувати `Audiowide`.

## Загальна структура сторінки

Головна сторінка складається з чотирьох основних зон:

1. Header.
2. Hero / main content.
3. Auth panel.
4. Footer.

Сторінка має бути адаптивною для desktop, tablet і mobile.

## Header

Header розташований у верхній частині сторінки.

### Ліва частина

У верхньому лівому куті має бути назва гри:

`Eclipcity`

Візуально це має бути перший стабільний brand-сигнал сторінки.

Рекомендації:

1. Шрифт: `Audiowide`.
2. Колір: `Ghost White` або `Toxic Lime` для акценту.
3. Можна додати тонкий neon-hover або underline-ефект, але без перевантаження.

### Центральна частина

У верхньому меню має бути кілька пунктів:

1. `Про гру`
2. `Як грати`

Пункти меню мають бути простими, читабельними й не виглядати як важкі кнопки.

Рекомендації:

1. Шрифт: `Space Mono`.
2. Колір: `Ghost White`.
3. Hover: `Neon Magenta` або тонкий border/underline.
4. Активний пункт можна позначати `Toxic Lime`.

### Права частина

У header можна залишити простір для майбутніх дій або мовного перемикача, але основна авторизація має бути в правій панелі hero-секції, а не в header.

## Main / Hero Area

Основна частина сторінки має бути поділена на дві смислові зони:

1. Зліва і по центру - візуал гри.
2. Справа - панель реєстрації або авторизації.

На desktop hero має займати перший екран сторінки так, щоб візуал і auth panel були видимі одразу.

## Game Visual Area

Зліва і по центру має бути зображення гри або тематичний візуал.

Поки немає готового арту, можна використати placeholder-візуал згідно тематики:

1. Нуарне cyberpunk-місто.
2. Темний тунель.
3. Неонове світло.
4. Втікачі або силуети людей.
5. Натяк на карткову гру: карти, символи предметів, фрагменти ігрового поля.

Візуал не має виглядати як випадкова stock-картинка. Він має підтримувати ідею втечі з Eclipcity.

Рекомендації для першої версії:

1. Зробити темний full-height visual block.
2. Додати поверх нього короткий атмосферний текст або tagline.
3. Не ховати основну назву гри тільки в header - бренд має бути помітним уже в першому екрані.
4. Підготувати місце, куди пізніше можна буде додати справжній арт.

## Auth Panel

Справа має бути розташована панель для реєстрації або авторизації.

Панель має підтримувати два режими:

1. `Login`
2. `Register`

Перемикання між режимами може бути зроблене через tabs або segmented control.

### Login Fields

Поля для входу:

1. Email або username.
2. Password.
3. Login button.
4. OAuth buttons, якщо вони вже доступні в реалізації.

### Register Fields

Поля для реєстрації:

1. Username.
2. Email.
3. Password.
4. Confirm password.
5. Register button.
6. OAuth buttons, якщо вони вже доступні в реалізації.

### Auth Panel Style

Рекомендації:

1. Background: `Deep Slate`.
2. Border: `Panel Border`.
3. Primary CTA: `Toxic Lime`.
4. Secondary action / switch mode: `Neon Magenta`.
5. Error states: `Alert Red`.
6. Допоміжний текст: `Muted Steel`.

Auth panel має бути чітким і функціональним, без зайвого декоративного шуму.

## Footer

Footer має бути внизу сторінки і відокремлений кольором від основного контенту.

Рекомендації:

1. Background: темніший або контрастний відтінок від основної секції, наприклад `Deep Slate`.
2. Top border: `Panel Border` або тонкий неоновий акцент.
3. Текст: `Muted Steel`.
4. Акценти при hover: `Neon Magenta` або `Toxic Lime`.

Footer має містити:

1. Рік.
2. Мови перекладу: `UKR`, `ENG`.
3. Іконки соціальних мереж:
   - TikTok
   - Threads
   - Instagram
   - YouTube

Соціальні іконки мають бути візуальними, не текстовими кнопками. Якщо в обраній ікон-бібліотеці немає потрібної іконки, можна тимчасово використати простий текстовий fallback або підключити окремі brand icons пізніше.

## Responsive Behavior

### Desktop

1. Header зверху.
2. Візуал зліва і по центру.
3. Auth panel справа.
4. Footer знизу.

### Tablet

1. Header лишається зверху.
2. Візуал може бути зверху або ліворуч, залежно від ширини.
3. Auth panel має залишатися добре видимою.
4. Меню не має ламатися або перекривати назву гри.

### Mobile

1. Header стає компактним.
2. Меню можна сховати в menu button або зробити коротким рядком.
3. Візуал розташовується над auth panel.
4. Auth panel займає майже всю ширину.
5. Footer елементи можуть переноситися в кілька рядків.

## Suggested Future Source Structure

Коли почнеться реалізація, файли можна розмістити в `src/`.

Можлива структура:

1. `src/pages/HomePage.jsx`
2. `src/components/layout/Header.jsx`
3. `src/components/layout/Footer.jsx`
4. `src/components/auth/AuthPanel.jsx`
5. `src/components/home/GameVisual.jsx`
6. `src/styles/theme.css`
7. `src/styles/home-page.css`
