# Testing

Проект має окремі юніт-тести для фронтенду та бекенду. Вони не потребують
підключення до бази даних або SMTP, бо перевіряють чисту валідацію та утиліти.

## Commands

```bash
npm run test
```

Запускає всі юніт-тести: спочатку фронтенд, потім бекенд.

```bash
npm run test:frontend
```

Запускає фронтенд-тести через вбудований `node:test`.

```bash
npm run test:backend
```

Запускає бекенд-тести через `unittest` з Python-віртуального середовища
`.venv`.

## Frontend Coverage

Файл: `tests/frontend/lobbyName.test.mjs`

Покриває:

- дефолтну назву лоббі для порожнього поля;
- дозволені символи для назв лоббі;
- заборонені символи;
- мінімальну та максимальну довжину назви;
- передачу перекладених повідомлень валідації.

## Backend Coverage

Файл: `tests/backend/test_lobby_units.py`

Покриває:

- нормалізацію та валідацію назви лоббі;
- дефолтну назву лоббі в API-схемі;
- обмеження кількості гравців;
- дозволені кольори команд;
- нормалізацію lobby code;
- формат endpoint `/lobby/{id}`;
- генерацію 5-символьного lobby id.
